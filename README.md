# Portfólio — Sidney Santos Neponeceno

Site pessoal desenvolvido com HTML5, CSS3, JavaScript e Bootstrap 5.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `portfolio_sidney` no Visual Studio Code.
3. Abra `index.html` no navegador. Para uma experiência melhor, use a extensão **Live Server** do VS Code.
4. O Bootstrap e as fontes são carregados por CDN, então é necessária conexão com a internet para esses recursos.

## Estrutura
- `index.html` — conteúdo e estrutura do site.
- `css/style.css` — identidade visual e responsividade.
- `js/script.js` — interações e pequenos comportamentos.
- `assets/` — fotografias utilizadas no portfólio.

A seção de projetos acadêmicos contém cartões-modelo. Substitua-os pelos projetos reais, descrições e links dos repositórios antes de publicar.

## Antes de publicar
- Confira se o endereço do Instagram está correto.
- Confirme o nome da instituição do curso preparatório bancário/administrativo.
- Atualize os projetos com links reais do GitHub quando estiverem prontos.
- Revise os dados de contato antes de publicar o site.
